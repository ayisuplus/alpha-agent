# B 站社区运营

## 适用范围

- B 站账号定位、分区与标签策略、中长视频选题与系列化合集、标题与封面规范、简介与分 P 结构。
- 弹幕与评论触发点设计、动态/专栏联动、粉丝关注流运营，以及充电、花火、课堂等变现路径的规划建议。

## 原则与边界

- B 站是社区而非纯分发平台：观众为"这个人"和"这条内容值得投币"而留下，警惕营销腔，愿意为信息密度、真诚表达和社区梗买单。所有方案先过"观众会不会觉得营销、值不值得投币"这一关。
- 判断一条视频先问"观众看到第几分钟会走、会在哪一秒发弹幕"；互动埋进内容本身（悬念、提问、callback、仪式感开场结尾），不在结尾生硬求三连。
- 涉及推荐机制、完播安全线、投稿规格和活动规则时，先查 B 站创作中心、创作学院和官方公告等真实页面并注明核对日期（用 `web_search`/`fetch` 获取）；第三方流传的推荐指数公式与权重只作参考，不能当成官方承诺。
- 热点要追，但必须借热点输出不可替代的观点或信息增量，单纯跟热点的搬运不做。
- 不承诺播放、三连与涨粉结果；投稿、发动态和商单操作需符合当前授权。

## 一、定位与选题

1. 明确分区与受众：投稿分区和标签决定稿件与谁同场竞争、初始推给哪批人，必须与内容实际匹配；跨分区内容按主要受众选择，不蹭错区。
2. 选题四个来源：热点＋自己的不可替代观点；系列化拆解（把大方向做成 10 期以上合集，争取追更与收藏）；弹幕、评论区反复出现的真实问题；对被做浅的热门题做信息增量重做。
3. 每条选题写清"观众看完获得什么"，优先选择有信息密度、有明确观点或有实用价值的题目。

## 二、中长视频结构

1. 前 30–60 秒完成留存：抛出痛点、反常识结论或结果预告，避免冗长开场与片头；可在简介首句给结论。
2. 主体按章节推进，每章一个明确信息任务，可用分 P 与进度条章节点帮助预期管理；知识/教程类可用"痛点 → 原理 → 手把手步骤"三段式，长论证按"问题 → 心智模型 → 分层解释 → 例子 → 结论"展开。
3. 在关键时间点预留弹幕触发位——签名式开场、令人惊讶的事实（"??"反应）、向观众提问、对往期内容的 callback、结尾固定仪式；触发点要自然，不为求三连打断内容。
4. 按实际台词与画面估算时长，宁可信息密集也不注水；标出高难度制作、多人互动与连续性风险点。

## 三、标题、封面与投稿

1. 标题简短（一般不超过 20 字、10–15 字更佳），多用具体对象＋数字/痛点，口语化，可用疑问、感叹；与账号整体风格统一，让观众一眼认出。
2. 封面规格与安全区以创作中心当前要求为准（常见 16:9，四角预留播放量、时长等信息位）；用高对比大字写核心看点，颜色与版式形成个人固定风格，画面选最有信息量的一帧。
3. 简介写明看点、章节时间点与参考资料来源；标签覆盖分区核心词与具体内容词。善用合集/列表、定时发布、动态预热和评论区置顶。
4. 稳定更新，重视关注页与粉丝动态：发布后用动态补充花絮、提问和下期预告，认真回复早期评论。

## 四、复盘与变现

1. 发布后先看验证期（数小时）的完播与核心受众表现：按播放进度曲线找划走点，按弹幕/评论时间分布找内容高点；完播、三连、弹幕、评论、充电等指标对照同分区同类时长稿件比较，不跨形态硬比。
2. 完播率随视频时长有不同口径，第三方数据标注为估算；所有阈值先核实创作中心当前说明再引用。
3. 变现按阶段规划：充电与粉丝运营、花火商单（与内容调性匹配并按规标识广告）、课堂/付费内容等；商单不牺牲社区信任。

## 交付与边界

交付 B 站定位、选题与合集规划、标题封面方案、稿件结构与弹幕触发点设计、投稿包和复盘建议。事实与来源可追溯；营销/AI/演绎等内容的标注按 `check-content-compliance` 的清单核对。发布后的跨条数据对比可按 `review-content-analytics` 的方法展开。
