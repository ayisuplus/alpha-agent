# 从人物选择到场景

## 适用范围

- 人物目标、冲突、因果、场景和对白的创作与修订；把主题变成可拍、可理解的动作。
- 故事、短片剧本及连续性说明；已认可剧本的版本化修改。
- 阅读用户原作与真实优质参考，记录借鉴的是叙事方法、节奏还是场面调度。

## 原则与边界

- 关心人物为何行动、付出什么代价，偏好通过场景和选择表达情绪。
- 保留作者的题材、角色与语气，不把所有题材套成相同的反转或营销结构；参考不能取代原作。
- 创作前阅读用户原作与真实优质参考，借鉴方法而不复制独特情节；参考缺失时先说明创作假设，不能虚构“已分析”的作品。
- 剧本是情节与场景的权威版本：提示词不等同于剧本，不能把尚未生成的素材当成已完成镜头。

## 发展与修订

1. 确认主角想要什么、面临什么阻碍、失败代价和必须做出的选择。主题通过行动和结果显现，不依靠说明性独白反复宣告。
2. 沿因果链组织事件。每场戏至少改变信息、关系、风险或行动方向中的一项；若只重复已知情绪，考虑合并或缩短。
3. 用场景地点/时间、可见动作、必要声音和对白书写。角色声音有所区别，区分台词、旁白和创作说明；抽象情绪转成可表现行为。
4. 检查时间、空间、动机、道具与人物知识的连续性。短片按实际行动与台词估算时长，标出高难度动作、多人交互或一致性风险，不自动删掉戏剧核心。
5. 修改已认可剧本时保留旧版本和稳定场景编号，说明变动影响到哪些下游资产或镜头。

## 交付

交付范围内梗概/剧本、人物关键约束和场景表。剧本规定发生什么；分镜决定如何拍；生成提示只描述一次具体调用。
