# 从原始数据到分析报表

## 适用范围

- Excel/CSV 数据的导入清洗、公式处理、透视表、条件统计、图表生成与数据报表。
- 报表面向管理决策、财务对账、业务追踪、调研汇总等场景。
- 多表关联、数据口径核对与可审阅的 .xlsx/.csv 成品交付。

## 原则与边界

- 先确认“每一行代表什么”再动手：数据来源、每列含义、每行的统计单位，以及用户想回答的具体问题。
- 重视数据口径与公式可审计性：不为了好看而改数据，不在缺失信息时编造填充值；缺失值不编造填充。
- 多表关联时说明关联键与连接逻辑；口径不一致时向用户确认而非静默合并。
- 不声称未经核实的数据为最终结论；标记数据缺口、未核实口径和需人工复核区域。
- 需要文档化交付时提供结果表与口径说明；需要演示图表时提供可嵌入的数据与建议图表类型。

## 处理决策

- 数据清洗：检查缺失值、重复行、异常值和格式不一致；处理规则写成可追溯的记录，不静默删除或修改。
- 公式与计算：使用可审计的方式（命名区域、公式说明附注），避免长链嵌套难以排查的公式。口径变更时保留前后对比。
- 透视与汇总：先确认分组维度与聚合方式（求和/计数/均值/占比），说明过滤条件和排序规则。
- 多表关联：声明关联键与连接类型（左/内/全），说明关联前后行数变化。
- 条件统计：COUNTIF/SUMIF/AVERAGEIF 等条件写清范围与条件值，不把条件藏在公式里不说明。
- 图表：选择与数据匹配的图表类型（趋势→折线/柱形，占比→饼图/环形，分布→直方图/箱线），标题含「什么 + 什么维度 + 什么时间」。
- 涉及金额和百分比时标注口径（含税/不含税、同比/环比、样本量）。

## 工具用法

- 读取源文件：用 OMP 原生 `read` 按路径读 xlsx/docx/pdf 等文档转为 Markdown 理解内容；csv/txt 直接按路径读取。
- 表格生产与编辑用单一工具 `alpha_office`，按路径进、按路径出，永不覆盖原件：
  - `inspect`：列出工作簿、工作表、单元格区域、表格与图表等可编辑地址；
  - `edit`：按地址修改已有 xlsx/csv，输出 `<原名>.alpha-v<N>.<扩展名>`，带前后预览；
  - `create`：表格数据→xlsx（含公式、图表、报表），写入项目内 `outputs/`；
  - `convert`：docx/xlsx/pptx/odf/html/pdf 互转（如 xlsx→pdf 报表）；
  - `pdf`：合并/拆分/旋转/水印/按页提取（如报表分发前的整理）；
  - `preview`：渲染指定页或工作表为 PNG 自检。
- 交付前用 `preview` 自检公式结果、汇总行与明细一致、图表与格式正确；工具返回 `{ summary, artifacts: [{ path, kind, sha256, preview? }] }`，产出都写在项目内。
- 超出能力范围时（如 LibreOffice 缺失导致无法渲染或转换）如实上报缺口，不虚构处理结果。

## 交付

默认交付可审阅的 .xlsx 或 .csv 文件，含公式说明、数据口径记录和图表。输出前自检：公式无引用错误、汇总行与明细一致。
