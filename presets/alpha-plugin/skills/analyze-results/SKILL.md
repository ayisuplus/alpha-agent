# 从原始记录到统计结论

## 适用范围

- 实验日志与结果文件的整理和一致性检查；分析计划（估计量、统计单位、配对与嵌套结构、主要比较）。
- 描述统计与分布检查；效应量、区间估计与必要的假设检验；多种子、多数据集、多模型结果的汇总。
- 多重比较与探索性分析的披露；人工标注与模型评判的一致性；科研图表、结果表和可重跑的分析脚本。
- 以 AI 实验的种子、数据集、测试样本和重复测量为重点，也处理一般实验与观测数据。

## 原则与边界

- 好的分析在看结果之前就定下主要比较：不因结果更显著而更换分析单位、删除异常值、改主指标或挑选随机种子。
- 结论强度跟着设计走：描述、关联和经设计支持的因果推断分开写；相关不写成因果，不显著不写成"没有差异"，p 值不写成假设为真的概率。
- 所有数字都能从原始记录和脚本重算；图表审美不能改变数据；样本不足时只给描述性结论，并说明还需要哪些数据。
- 平台与库的版本会变化；涉及具体版本、口径与限制时核对官方文档或实测并注明日期，不凭记忆宣称当前行为。
- 原始数据或分析环境不可用时先上报缺口，不凭汇总表臆造分析；分析环境缺少所需库时说明替代方案，或请用户授权安装，不自行扩大依赖。

## 输入与前置阅读

1. 读研究问题、实验方案（主要指标、主要比较、种子与划分设计）、原始日志与结果文件及字段说明。没有方案时先与用户确认主要比较，再看结果。
2. 保留原始数据不覆盖，处理步骤写成脚本；沿用项目已有的分析环境，不擅自新增依赖。
3. 选择方法、校正方式和报告格式时读取 `references/statistics-guide.md`。
4. 只审查分析方案时，指出设计问题、能支持的结论和需要的数据即可，不预设检验结果。

## 工作步骤

### 1. 盘点数据

- 清点记录数和真正独立的单位数；列出缺失、重复、失败运行、异常值和已有的排除规则。失败或中断的运行计数报告，不静默丢弃。
- 检查一致性：同一设置的配置是否一致、指标计算版本是否相同、结果是否来自按验证集选出的检查点而不是测试集上最好的那个。
- 画出数据结构：哪些观测配对（同一种子、同一测试样本、同一数据集上的两个模型），哪些嵌套（样本属于数据集、多次采样属于同一输入）。多个 epoch 或检查点不是独立重复。

### 2. 描述与分布检查

- 先报告每个设置的原始分布：各种子的值、均值、中位数、标准差、最小值与最大值；样本很少时直接列出每个值。
- 把全部数据点画出来（点图、带散点的箱线图），而不是只画柱子；检查偏态、离群和双峰。异常值先查原因（程序错误、训练发散），排除必须依据事先规则或写明理由，并报告排除前后的结果。

### 3. 效应与不确定性

- 主要结果用效应量表达：带单位和方向的绝对差值；需要相对变化时注明基数，基数很小时相对变化容易夸大。
- 区间估计与波动来源对应：训练随机性用跨种子的配对差值及其区间；测试集抽样用对测试样本的配对自助法（bootstrap）区间；两者都重要时分别报告，或按"种子—样本"层次重采样。
- 重采样以独立单位或簇为单位；小样本重采样不能凭空增加证据。

### 4. 必要的假设检验

- 检验服务于事先确定的主要比较，不对所有组合做地毯式检验。按设计选择方法（配对差值检验、置换检验、配对自助法、配对分类结果的 McNemar 检验、多数据集比较的 Wilcoxon 符号秩检验或 Friedman 检验加事后检验），细节见参考文件。
- 写明检验的前提与诊断，不凭一次正态性检验机械地切换方法。
- 多重比较：事先确定控制族错误率（如 Holm）还是错误发现率（如 Benjamini-Hochberg），并报告校正方法。探索性发现标注为需要在新数据上确认。
- 完整报告：样本量与单位、统计量、精确 p 值、效应量和区间。不显著时给出区间，说明能排除多大的效应，而不是宣称"两者相同"。

### 5. 汇总与稳健性

- 多数据集、多任务：先逐项报告，再给事先确定的汇总（平均排名、胜平负计数、四分位均值等稳健汇总）；尺度不同的指标不直接平均。
- 敏感性分析：换一种合理的汇总方式，或去掉影响最大的单个数据集或种子，看结论是否改变。
- 超参数搜索：报告全部配置的结果分布或随预算变化的期望最佳结果，不只报最好的一次。

### 6. 人工评测与一致性

- 报告标注者人数、培训方式、每项被标注的次数；一致性指标与数据类型匹配（如 Cohen's κ、Krippendorff's α）；有序评分按有序数据处理。
- 以模型为评判者时，用人工标注子集报告两者的一致性。

### 7. 图与表

- 图表由脚本直接从分析结果生成；标明单位、指标方向、样本数，以及误差条是标准差、标准误还是置信区间（写明水平）。
- 保留配对与分组结构（例如用连线表示配对）；优先显示全部数据点；坐标轴截断要标出；使用对色觉障碍友好的配色；导出矢量格式并附生成脚本。
- 结果表统一小数位，位数与不确定性相称；"最好"加粗只在差异超过不确定性时使用，或在表注中写明规则。

## 交付物

- 分析脚本与运行命令、输入文件定位与校验和、过滤与排除规则、中间结果表。
- 结果表与图（含生成脚本）；每个主要结论的效应量、区间、检验与校正方法；写入报告的每个数字都附来源文件、计算方法与区间定义。
- 分析计划中的统计单位、配对关系与主要比较保持与实验方案一致，便于后续按 `analyze-results` 的步骤复算。
- 结论分级：描述性 / 关联性 / 经设计支持的因果推断；事先计划的确认性结果与探索性结果分开；局限与需要补充的数据。

## 验收依据

- 从原始文件运行脚本能重现报告中的每个数字；统计单位与配对结构有明确说明；误差条与区间定义完整。
- 排除的数据有记录和理由；没有事后更换主指标或挑选种子；效应量与区间是主要表述，p 值不单独充当结论。
- 只有汇总表、没有原始数据时，只做有限分析并说明；不从均值反推方差，不编造缺失的种子结果。
