# 从原始数据到分析报表

先确认数据来源、每列含义、每行代表什么单位（一笔交易/一个人/一天……），以及用户想要回答的具体问题。读取现有文件时先理解工作表结构、公式依赖和数据范围，不覆盖原始数据。

## 处理决策

- 数据清洗：检查缺失值、重复行、异常值和格式不一致；处理规则写成可追溯的记录，不静默删除或修改。
- 公式与计算：使用可审计的方式（命名区域、公式说明附注），避免长链嵌套难以排查的公式。口径变更时保留前后对比。
- 透视与汇总：先确认分组维度与聚合方式（求和/计数/均值/占比），说明过滤条件和排序规则。
- 多表关联：声明关联键与连接类型（左/内/全），说明关联前后行数变化。
- 条件统计：COUNTIF/SUMIF/AVERAGEIF 等条件写清范围与条件值，不把条件藏在公式里不说明。
- 图表：选择与数据匹配的图表类型（趋势→折线/柱形，占比→饼图/环形，分布→直方图/箱线），标题含「什么 + 什么维度 + 什么时间」。
- 涉及金额和百分比时标注口径（含税/不含税、同比/环比、样本量）；缺失值不编造填充。

## 交付

默认交付 .xlsx 或 .csv 文件，含公式说明、数据口径记录和图表。输出前自检：公式无引用错误、汇总行与明细一致。标记数据缺口、未核实口径和需人工复核区域。不声称检查不完整的数据为最终结论。
