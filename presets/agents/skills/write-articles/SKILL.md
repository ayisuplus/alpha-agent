# 从想清楚到写清楚

## 输入与前置阅读

1. 确认文体（深度长文、评论或观点、科普、随笔、演讲稿、书评、特写）、读者（身份、已有知识、为什么会读）、场合与渠道（公众号、报刊、演讲现场、内部分享）、篇幅与截止时间、署名与口吻（第一人称、机构口吻）。
2. 读取用户素材：采访记录、数据、资料、已有草稿、参考样文。有样文时先分析它的语气、句长、段落节奏和用词习惯再模仿，不照搬内容。
3. 改稿任务先确认修改范围：只改语言 / 可以调整结构 / 可以增删论点，以及哪些表达必须保留。
4. 改稿与发布前自查时读取 `references/editing-checklist.md`。

## 工作步骤

### 1. 立意：一句话中心论点

- 用一句话写出文章要让读者相信或理解的核心，再写一句"为什么是现在、为什么是这些读者"。写不出来时回到素材或向用户提问，不开始铺陈。
- 列出读者最可能的疑问和反对意见，决定文章必须回答其中哪几个。

### 2. 素材盘点与事实核对

- 把素材分成四类：事实与数据（带来源）、案例与场景、引语、观点与推断。关键事实记录来源；数字核对单位、时间、统计口径和原始出处。
- 列出素材缺口：支撑论点还缺什么证据或例子。能检索的用当前可用能力核实并记录来源；不能核实的标为待核验或删除，不用想象补齐。
- 引语只用有出处的原话，转述不改变原意；不编造专家、受访者和经历。

### 3. 结构与大纲

- 选择与文体匹配的结构：
  - 评论与观点：论点先行 → 理由与证据（由强到弱或由浅入深）→ 回应反方 → 落到含义或行动。
  - 深度长文与特写：场景或人物切入 → 引出问题 → 分层展开（背景、机制、影响、分歧）→ 回到开头的人或场景。
  - 科普解读：从读者已知的事或常见误解出发 → 把一个核心概念讲透（类比加上它的适用边界）→ 证据 → 这对读者意味着什么；科学上尚无定论的地方写明不确定。
  - 演讲稿：一条主线、不超过三个要点、口语化短句，用重复和提示语帮助听众跟上，标出停顿并估算时长。
  - 随笔：一个具体的触发点 → 联想与思考 → 回到具体。
- 大纲写到段落级：每段一句主题句加上要用的素材。篇幅较长或观点敏感时，先把大纲交用户确认再写全文。

### 4. 成稿

- 开头：前两三句给出读下去的理由，可以是一个具体场景、一个反直觉的事实、一个尖锐的问题，或直接亮出论点；不写空泛的时代背景铺垫。
- 段落：一段一个意思，主题句在前；段与段之间靠逻辑关系衔接，而不是堆砌。
- 论证：观点配证据，证据配解释；类比说明适用边界；承认反例和局限会增加可信度。
- 语言：具体的名词和动词优先，少用形容词和程度副词；长短句交替；删去套话、空泛升华和模板化对仗；术语第一次出现时用读者能懂的话解释。
- 结尾：回到中心论点并再推进一步（含义、行动或开放问题），不重复摘要，不喊口号。

### 5. 改稿：三级修改

- 结构层：中心论点是否清楚；段落顺序是否服务论证；有无跑题、重复或缺失的环节；开头结尾是否呼应。
- 段落层：主题句是否明确；证据是否支撑本段；过渡是否自然；篇幅分配是否与重要性匹配。
- 句子层：删冗余、拆长句、换成具体的词、统一术语与称谓、修正语病和标点；朗读检查节奏。
- 交付时说明主要改动及理由；涉及观点或事实的改动先向作者确认；保留作者的声音，不把所有文章改成同一种腔调。

### 6. 标题、导语与版本

- 标题准确概括并有吸引力，给出 3–5 个候选并说明各自的侧重；不用与正文不符、夸大或恐吓式的标题。
- 按需提供不同版本：全文、短版、摘要或导语、演讲口播版、分享语；各版本的事实与观点保持一致。

## 交付物

- 立意说明（中心论点、读者、必须回答的问题）与段落级大纲。
- 成稿或修改稿（附修改说明）、标题候选与导语。
- 事实与来源清单：关键事实、数字、引语 → 来源 → 核验状态，待核验项单列。
- 需要作者确认或补充的事项：缺失素材、敏感表述、授权与署名。

## 验收依据与能力缺口

- 验收：能用一句话说出中心论点；每段都服务于它；关键事实可追溯来源；没有编造的引语、数据或经历；没有明显的套话和语病；篇幅与格式符合要求。
- 缺少素材或无法核实关键事实时，交付带待核验标记的稿件和缺口清单，不以编造填充。
- 发布、投稿、联系媒体或以用户名义发送都不是默认动作，需要用户明确授权；传播效果以发布后的真实数据为准，不做承诺。
