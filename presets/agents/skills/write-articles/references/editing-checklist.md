# 改稿与发布前自查清单

## 立意与结构

- [ ] 能用一句话说出中心论点，全文都在服务它
- [ ] 读者最可能的疑问和反对意见已经回答
- [ ] 开头三句之内给出读下去的理由；结尾没有重复摘要或喊口号
- [ ] 段落顺序有逻辑；没有跑题、重复或缺失的论证环节

## 事实与引用

- [ ] 每个数字都核对了单位、时间、口径和原始出处
- [ ] 引语有出处，转述没有改变原意；没有编造的人物、引语和经历
- [ ] 事实、观点、推测、虚构区分清楚；不确定的内容写明不确定
- [ ] 引用他人文字注明出处；没有大段搬运或洗稿

## 语言

- [ ] 删除套话、空泛升华、堆砌的排比和模板化句式（如滥用"不是……而是……"、"在……的背景下"、"值得一提的是"）
- [ ] 具体名词和动词优先；"非常""极其"等程度词克制使用
- [ ] 长句拆开，主语与谓语靠近；同一概念前后用词一致，称谓统一
- [ ] 术语第一次出现时有解释，缩写有全称
- [ ] 朗读一遍检查节奏与拗口处；演讲稿必须朗读并计时

## 规范

- [ ] 标点符合 GB/T 15834-2011《标点符号用法》
- [ ] 数字用法符合 GB/T 15835-2011《出版物上数字用法》；文学类作品另有惯例时按惯例并保持全文统一
- [ ] 人名、地名、机构名和专有名词写法正确
- [ ] 中英文混排时，全角与半角标点、空格和单位写法统一
- （两项标准的现行状态于 2026-09-27 在全国标准信息公共服务平台核对；投稿单位有自己的体例时以其要求为准。）

## 发布前

- [ ] 标题与正文相符，没有夸大、恐吓或误导
- [ ] 面向中国平台发布时，营销与广告表述、医疗或金融或教育等资质、AI 生成与虚构演绎等标注交内容合规审核员复核
- [ ] 批评真实个人或机构有事实依据且表述克制；涉及隐私的信息已获授权或去除可识别信息
- [ ] 图片、图表和引用素材的来源与使用授权已确认

## 常见问题与改法

| 问题 | 例子 | 改法 |
|---|---|---|
| 空泛开头 | "随着科技的飞速发展……" | 换成具体的场景、事实或问题 |
| 用形容词代替证据 | "效果非常显著" | 给出数字、对比或例子 |
| 结论跳跃 | 由一个案例推出普遍规律 | 限定范围，或补充证据 |
| 模板对仗 | 连用"不是 A，而是 B" | 直接陈述，只保留确有必要的一处 |
| 术语堆砌 | 一句里有多个未解释的术语 | 拆句，逐个解释或删去 |
| 层层铺垫 | 论点出现在第五段 | 把论点提到开头，背景按需穿插 |
