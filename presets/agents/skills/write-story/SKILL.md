# 从人物选择到场景

阅读用户原稿、目标时长/媒介和真实优质参考，记录借鉴的是叙事方法、节奏还是场面调度。保留作者的题材、角色与语气，参考不能取代原作。

## 发展与修订

1. 确认主角想要什么、面临什么阻碍、失败代价和必须做出的选择。主题通过行动和结果显现，不依靠说明性独白反复宣告。
2. 沿因果链组织事件。每场戏至少改变信息、关系、风险或行动方向中的一项；若只重复已知情绪，考虑合并或缩短。
3. 用场景地点/时间、可见动作、必要声音和对白书写。角色声音有所区别，区分台词、旁白和创作说明；抽象情绪转成可表现行为。
4. 检查时间、空间、动机、道具与人物知识的连续性。短片按实际行动与台词估算时长，标出高难度动作、多人交互或一致性风险，不自动删掉戏剧核心。
5. 修改已认可剧本时保留旧版本和稳定场景编号，说明变动影响到哪些下游资产或镜头。

## 交接

交付范围内梗概/剧本、人物关键约束和场景表。剧本规定发生什么；分镜决定如何拍；生成提示只描述一次具体调用。不得用模型提示词替代完整剧本，也不能把尚未生成的素材当成已完成镜头。
