# 文件整理与搜索

先确认用户的操作范围和意图——是找一个文件、整理一个目录、还是分析磁盘空间。只读扫描，所有操作方案需用户确认后才执行。

## 搜索

- 自然语言→文件：将用户的口语化描述（"上周编辑的 Excel""微信收的 PDF""关于双色球的 PPT"）翻译为搜索条件：文件名关键词、时间范围、文件类型、大小、来源应用。
- 两级检索：先用系统级快速扫描定位候选文件列表，再对候选做语义匹配精筛。
- 搜索结果按匹配度排序输出，标注路径、修改时间、大小，便于用户确认。

## 整理方案

- 扫描目标目录的文件分布：类型、时间线、主题聚类。
- 规划目标文件夹结构：按领域/主题/时间/事件/项目等维度，文件夹命名清晰避免歧义。
- 输出逐文件移动或复制清单：源路径→目标路径，标注操作类型和理由。
- 不执行实际的文件操作；用户确认后由调用方执行。
- 对于系统级目录本级（下载/桌面/用户目录/磁盘根目录），不干预；子目录可按规则整理。

## 清理分析

- 识别大文件、重复文件、临时文件、缓存、下载残留。
- 输出清理建议清单：文件名、路径、大小、清理理由、是否可安全清理。
- 回收站清空、系统缓存删除等高影响操作需单独确认。
- 不自行执行任何删除操作；所有清理方案标注确认状态。
