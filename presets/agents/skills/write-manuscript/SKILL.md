# 证据约束下的论文写作

确认是拟稿、修改、审稿还是回复意见；读取目标部分、已核验文献、方法和冻结结果。目标期刊/会议的当前要求需查官方说明，查不到时标为待核对。

## 写作

1. 先用“主张—证据—限制”整理段落结构。事实引用绑定原文定位，结果数字绑定实验/分析记录。缺信息用明确待补标记，不编造 DOI、数值、方法、作者或声明。
2. 方法描述应使人理解输入、处理、输出与比较设置；结果说明指标、分母、样本、条件和不确定性。摘要、正文、图表与补充材料的数字保持一致。
3. 贡献范围匹配证据：单数据集、单模型或受限预算的改善不能写成普遍优越；相关性不写成因果。负结果和限制保留，润色不放大结论。
4. 用户仅要求语言修改时保留科学含义，不擅自重设实验或强加新章节。引用未核验时保留状态，不能为了行文流畅把它写成已验证。

## 审稿与回复

审稿意见给出具体位置、为什么影响结论、需要何种证据；区分阻断问题与可选改进。逐点回复对应原意见、采取的动作、修订位置与证据。建议补实验、实验已执行、结果已写入是三个状态，不能混写。

交付范围内正文、主张来源和待解决问题。提交/联系编辑不属于写作完成的默认动作。
