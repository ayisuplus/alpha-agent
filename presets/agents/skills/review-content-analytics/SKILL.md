# 内容数据复盘

先确认分析对象（单条内容 / 账号 /  campaign / 直播间）、平台、时间范围、数据来源与用户想回答的决策问题。没有真实数据时，交付指标定义、取数清单与复盘模板，不编造数字。

## 一、口径先行

1. 统一定义每个指标：曝光、点击/点击率、3 秒/5 秒留存、完播/完读（各平台对观看进度的计算不同，部分按时长梯度计算）、互动（赞、藏、评、转、弹幕、投币、在看、充电等）、涨粉、进店、成交。
2. 标明数据来源与可信度：平台官方后台实测、第三方工具估算（蝉妈妈、新榜、巨量算数等）、创作者或对方自述；第三方数据注明统计口径与时间。
3. 明确分析单位与样本量：单条对比需同形态、同长度区间、同发布条件；样本过小不下结论，只描述现象。

## 二、漏斗诊断

1. 按漏斗逐层定位：曝光（账号权重、话题、人群匹配）→ 点击（封面、标题、开头）→ 留存（进度曲线的划走点）→ 深度互动（收藏/评论/弹幕/回访反映的内容价值）→ 涨粉（持续关注理由）→ 转化（人群精准度与承接路径）。
2. 一层异常只归因于该层及相邻环节，不跨层臆断；区分内容问题、发布时间问题、账号阶段问题和平台规则变化。
3. 同时看绝对值与相对值：与自己历史基线、同合集其他条、同赛道对标账号比较；剔除刷量等异常样本，不为伪互动做解释。

## 三、周期复盘与对标

1. 周期复盘（周/月）统计更新频率、总曝光、均值与中位数、爆款率、涨粉、转化及内容结构分布，找出真正贡献结果的内容类型，避免被单条爆款带偏。
2. 对标拆解固定维度：账号定位与人设、选题结构、开头与标题封面模式、内容形态与更新节奏、互动引导、标签体系、变现方式；用真实可查数据，注明观察日期。
3. 复盘结论必须转成下一轮可验证的假设与动作清单（假设、预期指标、验证方式、样本量），每次只改动少数变量，形成 PDCA 闭环。

## 四、结果呈现

- 报告结构：结论摘要 → 数据口径与来源 → 漏斗/趋势分析 → 对标发现 → 问题与假设 → 下一轮实验清单。
- 图表服务结论：留存曲线、漏斗、内容类型对比、周期趋势；数字与图表一致，可回算。
- 只对已核对样本范围负责，不把相关当因果，不承诺未来数据；需要长期监控时说明监控指标与频率。

## 交付与边界

交付复盘报告、对标拆解、指标字典、取数模板与实验清单。获取后台与第三方数据需当前授权并遵守平台规则；发现刷数据、搬运等违规线索时如实标注并交合规方法处理，不提供规避手段。
