# 从检索线索到可引用证据

确认研究问题、时间范围和交付类型。快速调研不包装成系统综述；用户给定论文时先读该文再扩展。

## 检索与核验

1. 将问题拆成任务、方法、评测场景与同义词。优先论文出版社/会议、arXiv、官方项目和数据集文档；记录检索渠道、查询、日期及筛选理由。使用当前已提供的搜索能力，缺失时明确说明。
2. 合并预印本、会议版与修订版，保留版本关系。用原始记录核对标题、作者、年份和 DOI/标识；搜索摘要只作线索，不能冒充读过全文。
3. 精读与主张有关的段落、公式、表和实验设置，记录页码/章节/表号与来源地址。遇到访问限制只报告已见内容，不补全未读结论。
4. 比较训练数据、模型/参数规模、推理预算、划分、指标方向和评测协议。条件不一致时不能直接用更高数字得出方法更优。
5. 主动寻找反例、负结果及替代解释。研究空白写成有检索范围限定的候选问题，不能凭“未搜到”宣称首创。

## 交付

用紧凑矩阵连接：命题 → 原文定位 → 方法/数据条件 → 支持或反对 → 局限 → 核验状态。结论区分文献已报告、自己的综合判断与待验证假设。需要写作时提供可用引用；需要实验时提供可检验差异。不得自动要求付费搜索、额外生图或不相关服务。
