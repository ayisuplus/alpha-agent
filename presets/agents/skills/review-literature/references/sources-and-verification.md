# 检索渠道与核验清单

核对日期：2026-09-27。渠道的覆盖范围、访问方式和接口会变化，以实际访问结果为准；这里只写用途和常见陷阱，不提供任何可直接引用的文献条目。

## 渠道与用途

| 渠道 | 适合做什么 | 注意 |
|---|---|---|
| arXiv | 计算机与 AI 预印本全文；查看版本历史与提交日期 | 未经同行评审；不同版本结果可能不同，引用时注明版本；可能被作者撤回 |
| OpenReview | 部分会议（如 ICLR）的投稿、审稿意见与作者回复，公开程度依会议而定 | 审稿意见是争议线索，不是结论；被拒稿件可能后来在别处发表 |
| ACL Anthology | 自然语言处理会议与期刊论文及其官方书目信息 | 以其页面元数据核对条目 |
| DBLP | 计算机科学书目：作者、发表处、年份、卷期 | 只有书目信息，没有全文和引用关系 |
| Semantic Scholar、OpenAlex | 引用图谱：向前、向后追溯，相关论文 | 元数据可能合并错误或缺失，关键信息回到原文核对 |
| Google Scholar | 覆盖面广，"被引用"列表 | 可能限制自动访问；结果混有非学术来源 |
| 出版社数字图书馆与 DOI 解析（ACM DL、IEEE Xplore、Springer、Elsevier 等） | 正式版本、勘误和撤稿声明 | 可能有付费墙，读不到时如实标注 |
| 中文文献库（知网、万方、维普等） | 中文期刊、会议与学位论文 | 通常需要机构权限；无法访问时请用户提供全文 |
| 官方代码仓库、模型卡、数据集卡 | 实际实现、数据说明与许可证 | 代码与论文可能不一致；以论文为准，并记录差异 |

## 条目核验清单

- 标题与原文完全一致，包括大小写、冒号后的副标题。
- 作者全部列出且顺序正确；中文作者的拼音与英文署名不混用。
- 年份：预印本首次提交年份与正式发表年份区分，引用哪个版本就用哪个年份。
- 发表处：会议或期刊全称，主会与 workshop 区分；期刊写明卷、期、页码或文章号。
- DOI 能解析到同一篇论文；arXiv 编号带版本号时与所引内容一致。
- 没有撤稿或重大勘误；有勘误时注明并使用更正后的内容。
- 正文所引的具体内容确实出现在所标的位置。

## 常见错误

- 把预印本年份当成会议年份，或引用会议版却使用预印本版本中的数字。
- 把 workshop 论文写成主会论文。
- 标题相近的不同论文、作者名拼写差异导致合并错误。
- 二手引用：综述说"X 证明了 Y"，原文其实只在某个设置下观察到。
- 看似合理却查无此文的参考文献：每一条都必须在本轮检索中找到实际记录，否则标为未核验。

## 系统综述（仅在用户要求时）

- 事先写好研究问题、纳入与排除标准、检索式、渠道和时间窗，再开始检索。
- 标题摘要筛选和全文筛选分两阶段，记录每阶段的数量和排除原因；报告格式可参照 PRISMA 2020 的流程图与清单（Page et al., BMJ 2021;372:n71）。
- 引用追溯可参照 Wohlin 的滚雪球方法（EASE 2014）：从种子集出发反复向后、向前追溯，直到没有新的纳入文献。
- 质量评估写明维度（研究设计、数据、基线、统计、可复现性），不只给一个总分。

## 中文参考文献格式

- 国家标准 GB/T 7714-2025《信息与文献 参考文献著录规则》自 2026-07-01 起实施，全部代替 GB/T 7714-2015（来源：全国标准信息公共服务平台，核对日期 2026-09-27）。
- 学校、期刊有自己的模板或要求时，以其最新官方要求为准；模板仍沿用 2015 版时按模板执行，并告知用户存在版本差异。
