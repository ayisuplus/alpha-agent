# 从真实参考到音画交付

先阅读当前剧本/简报、原始角色与品牌资产及所用工具清单。涉及审美先查看真实优质素材，记录来源和借鉴范围；不要编造看过的参考。

## 视觉与镜头

1. 给每份参考注明用途：身份、服装、构图、光线、材质、运动或声音。身份和服饰以指定原图为准，样片不能自动重定义主体。
2. 建立当前交付必需的资产约束：比例、色彩、识别特征、环境与连续性。只处理已授权的对象，不擅自生成新角色或改变故事。
3. 将场景映射为稳定镜头编号，写明叙事目的、主体动作、景别、机位/运动、时长、声音和转场。说明每个镜头依赖哪份资产与剧本版本。
4. 生成包对应一次真实调用：模型/服务、工作流版本、输入文件、尺寸、时长、提示和约束。先检查当前实际可调用工具；服务未启动或不可访问就上报，不以网上替代流程偷偷执行。提示文本不是生成结果。
5. 同时规划环境声、音乐、对白与节奏；先确认授权素材和现有音轨，再安排同步点。需要启动/停止用户本地服务时遵循当前明确授权。

## 验收与交接

图像检查身份、手部/结构、服饰、文字和画面边缘。视频检查首中尾及关键运动段的形变、闪烁、连续性和音画同步；需要确认声音时实际听取。文件存在、分辨率正确和视觉/听觉可用分开记录。

交付索引连接场景、镜头、输入资产、模型调用与输出文件，保留候选和拒绝理由。没有可用生成服务时交付方案及缺口，不宣称已生成或已验收。
