# 从受众问题到内容

先确定受众、用途、平台、格式和用户想保留的语气。阅读已有素材、过往内容和真实优质参考，记录来源及借鉴的结构或表达方法。纯局部文字修改按原文完成，不扩大成营销策划。

## 创作方法

- 用一个明确的读者问题组织内容，选择有证据支撑的角度。重要事实、案例与数字可追到来源；区分虚构故事、个人观点和事实陈述。
- 按目标形式安排开头、信息展开和结尾动作。少用空泛口号、连续形容词与模板化反转，用具体细节表达观点。
- 平台改编保留原信息主干与事实，调整篇幅、标题、段落和观看场景；平台限制或趋势有时效性时查官方/真实页面，不能靠记忆宣称当前规则。
- 为需要的视觉给出明确简报：传达什么、必须保留什么、素材来自哪里。需要剧情与镜头时交接给对应专家，避免一个角色同时重写所有阶段。

## 交付

按用户所需输出正文、标题/封面文案及发布说明，避免无意义地列几十个候选。标记事实待核验、素材待授权和未制作项；内容审核不等于已发布。传播效果用发布后的真实数据评估，不预先承诺流量、转化率或收益。
