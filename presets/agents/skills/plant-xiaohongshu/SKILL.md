# 小红书种草策划

先读取账号定位、目标（种草/测评/攻略/引流/品牌合作）、产品或话题素材、已有笔记与数据、对标账号。小红书是"带社交属性的搜索引擎"，每篇笔记解决一个具体、可被搜索到的问题。

## 一、关键词与选题

1. 从真实搜索场景找词：在小红书搜索框输入核心词，记录下拉联想、相关搜索、结果页排序与高赞笔记标题；结合季节、场景、人群、痛点扩展长尾词。关键词反映生活方式与购买决策，不照搬通用搜索引擎的选词逻辑。
2. 判断每个词的搜索意图（找攻略 / 做对比 / 看测评 / 求避坑 / 找灵感），选题与意图一一对应；优先做自己有真实体验或信息优势的题。
3. 高收藏题型优先：攻略教程、避坑清单、步骤记录、真实对比、合集盘点；标题和选题要给出明确结果承诺，但不夸大、不虚构体验。
4. 建立选题库，按"核心词 × 场景 × 人群"批量规划，保持垂类稳定更新以积累账号权重。

## 二、封面与标题

1. 封面承担点击：首图用高清画面＋醒目大字，直接写痛点或结果（"看完能得到什么"），主体明确、版式统一；信息流中一眼可辨主题。点击率门槛等数值只作参考，以创作中心当前口径为准。
2. 标题控制在平台当前建议长度（常见 15–25 字），包含 1 个核心关键词，用"问题/人群＋具体结果"结构，可加数字、场景、时间等限定；不用空泛副词，不做与内容不符的标题党。
3. 图文笔记准备 3–6 张高清图：首图痛点/利益点，后续图按步骤、对比、细节、结果组织，必要时加简洁文字标注；视频笔记同样以前 1–3 秒和封面抓人。

## 三、正文与发布

1. 首行承接标题、迅速给价值；正文短段落、分点写清步骤或要点，自然嵌入 3–5 个长尾词（首尾各出现、中间分散），语言像真实用户分享，不生硬堆词——语义识别下关键词堆砌可能被限流。
2. 如实标注身份与合作关系：品牌合作、赠送样品、营销信息按平台规则标识；不写伪素人话术，不虚构使用经历和效果数据。
3. 话题标签选垂直精准词；善用合集、置顶笔记承接系列内容。发布后回复提问型评论并补充信息，评论区本身也是搜索与信任资产。

## 四、复盘

1. 对照曝光、点击（封面/标题）、停留与完读、收藏、评论、关注、搜索进店等数据定位问题；区分流量来自搜索还是推荐，分别优化关键词与封面选题。
2. 以创作中心等官方后台为准，CES 评分类公式与流量阈值为第三方/经验口径，先核实再引用，不向用户保证爆文。
3. 每轮迭代形成关键词与选题假设的验证闭环；跨平台对比与周期统计对接数据复盘方法。

## 交付与边界

交付关键词表（含意图判断）、选题库、笔记成稿（标题/正文/标签）、封面简报与发布说明。医疗、金融等受限品类先核资质与功效表达边界（对接合规方法），素材与肖像需授权。发布、私信与投流需当前授权，不承诺流量与转化。
