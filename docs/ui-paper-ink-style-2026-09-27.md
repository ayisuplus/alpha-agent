# 界面风格：纸与墨（2026-09-27）

参考 [Xiaomi MiMo 官网](https://mimo.mi.com/) 的视觉语言，把 Alpha 工作台从"薄荷青 + 直角"改为"暖纸 + 墨黑 + 鼠尾草绿"。参考站点的配色、字体与圆角数值于 2026-09-27 从页面的计算样式读取；本文只借用风格方向，没有复制其图片、文案或代码。

## 这种风格怎么描述

一句话：**暖纸底色上的墨色排版，用大量留白和极细的线来组织，唯一的装饰是点阵植物纹理。**

可以用这些词和设计师或模型沟通：

| 维度 | 说法 | 在 Alpha 里的体现 |
|---|---|---|
| 整体 | 温润极简、纸感、安静的科技感（warm / organic minimalism, calm tech） | 大留白，颜色少，没有渐变和重阴影 |
| 配色 | 纸与墨（paper and ink）、低饱和大地色 | 暖白纸 `#fcfaf8`，墨黑 `#1a1a1a`，鼠尾草绿 `#4b6a52`，沙色高亮 `#ebe5dc` |
| 字体 | 三种字体分工：楷体问候、系统无衬线正文、等宽数字 | 问候语与页面大标题用霞鹜文楷或系统楷体，数字、时间、快捷键用等宽字体 |
| 标题 | 轻字重、居中、章节感（editorial） | 标题字重 400–500，场景区标题夹在两条细线中间 |
| 按钮 | 墨色胶囊、细线描边胶囊（pill buttons） | 主操作是黑色胶囊，次操作是细线胶囊，"新建任务"是全屏唯一常驻的黑色按钮 |
| 卡片 | 纸上的白卡、12px 圆角、极细暖色边线（hairline） | 当前任务、设置导航、场景卡都是"从纸上抽出的一张白卡" |
| 高亮 | 荧光笔式底色（highlighter） | 场景卡标题下半截铺沙色，专家业务线标签用沙色底 |
| 纹理 | 半色调、点阵、抖动（halftone / dithering），植物学插画 | 首页问候语背后是程序生成的点阵蝴蝶 |
| 动效 | 打字机效果与闪烁光标 | 问候语每次启动逐字打出一次，之后光标 `_` 保持闪烁 |

## 设计规则

1. **颜色只表达意义。** 结构靠留白和细线；颜色用于状态（鼠尾草绿 = 运行、选中、完成，赭黄 = 待处理，砖红 = 失败）和主操作（墨黑）。
2. **每屏只有一个墨色重点。** 主按钮用黑色胶囊，其余按钮用细线胶囊或纯文字。
3. **白卡放在纸上。** 页面底是暖纸色，可点击的内容块用白色卡片，12px 圆角加 1px 暖色细线；悬停时边线加深、轻微上浮，不用大阴影。
4. **字重克制。** 正文 400，标题 500–600，不用 700 以上的粗体堆砌层级。
5. **装饰只有一处。** 点阵蝴蝶只出现在新建任务页；工作界面保持干净。
6. **数字用等宽。** 时间、耗时、token 数、快捷键使用等宽字体并对齐数字；含中文的说明文字不用等宽字体。
7. **可读性优先。** 所有正文颜色在纸色和侧栏底色上的对比度不低于 4.5:1；问候语压在点阵上时加纸色光晕保证清晰；尊重系统的"减少动态效果"设置（直接显示全文，不打字）。

## 实现位置

- 颜色、字体、圆角、阴影：`desktop/ui/src/styles/tokens.css`（新增 `--bg-highlight`、`--ink`、`--halftone`、`--radius-xl`、`--radius-pill`、`--shadow-card`，并补上此前被引用却未定义的 `--shadow-lg`）。
- 按钮、徽标：`desktop/ui/src/components/ui.css`。
- 点阵蝴蝶：`desktop/ui/src/components/Halftone.tsx`，在画布上按密度函数绘制交错排列的圆点，随容器尺寸重绘，不使用图片文件。
- 打字问候：`desktop/ui/src/components/Greeting.tsx`，每次启动只逐字打一遍；未打出的部分预先占位，居中文本不会跳动。
- 其余按组件样式文件调整：侧栏、新建任务页、输入框、时间线、右侧工作区标签、设置与专家库、自动化页面标题。

## 字体说明

- 问候语与页面大标题优先使用开源字体"霞鹜文楷"（LXGW WenKai），这也是参考站点使用的字体。电脑上没有安装时回退到系统楷体；英文字母先用 Georgia，避免楷体自带的全角西文字母间距过宽。
- 正文依次尝试 Inter、苹方、MiSans、HarmonyOS Sans、思源黑体、微软雅黑。
- 数字与代码依次尝试 Geist Mono、JetBrains Mono、Cascadia Mono、Consolas。
- 应用没有内置这些字体文件；安装霞鹜文楷后问候语效果最接近参考站点。

## 验证

- `bun run check` 通过；`bun run build:desktop-ui` 构建成功；`workbench-state`、`workbench-timeline`、`report` 界面状态测试通过。
- 在隔离工作区启动服务，用无头 Chrome 在 1440 与 1100 像素宽度下检查新建任务页（含打字过程）、任务时间线、追问模式、任务详情、设置（模型、专家库、运行）、自动化和命令面板。
- 正文与弱化文字的对比度按 WCAG 公式计算：纸色底上正文 16.7:1、次要文字 5.3:1、最弱文字 5.0:1；侧栏底上最弱文字 4.7:1。
- `scripts/probe-general-workbench.ts` 中对首页标题的检查已改为读取新问候语的无障碍名称。
