# 桌面界面恢复（2026-09-29）

用户要求释放 OMP 和天枢能力，同时保留美观的桌面入口及可视化模型、账号和配置操作。上次迁移隐藏设置和欢迎页属于实现偏差；本次保留原生执行内核，补回这些桌面能力。

## 实现范围

- 复用既有蝴蝶半色调动画、打字问候和纸色布局。首页有任务输入、工作目录、可搜索模型列表、思考强度和开始任务；草稿本地保存。
- 左侧设置入口和 Ctrl+, 快捷键。模型与账号页可选择默认模型、保存或删除 API Key，显示已有 OAuth 状态和凭据来源；不回传密钥正文。
- 模型目录读取 OMP ModelRegistry，配置写入 OMP Settings，凭据进入 OMP 自有存储。不再套用旧 Alpha 的模型白名单。
- 运行与工具页按上下文、模型、文件、工具等分组展示有 UI 元数据的原生标量设置，支持搜索、保存和重置。当前内核读出 373 个设置项；由原生注册表验证数值和枚举。
- 桌面字号和右侧工作区显隐可视化配置。本次没有恢复旧计划图、专家调度和旧执行循环。
- 正确识别原生默认模型后面的思考强度，例如 `opencode-go/mimo-v2.6-pro:high`；模型 ID 本身含冒号时保留原 ID。

## 验证

- `bun run check` 通过；`bun run test` 9 项通过、47 个断言。
- 集成测试使用临时 OMP 配置目录：写入测试凭据、保存模型及参数、验证不泄露密钥、拒绝非法配置、确认新 RPC 会话实际选择保存的模型，并删除测试凭据。
- 真实内置浏览器从首页选择 `xiaomi-token-plan-cn/mimo-v2.6-flash` 和 off，提交无工具测试，收到 `ALPHA_UI_OK`，会话显示对应模型和思考强度。
- 已安装程序的桌面探针确认欢迎画布、模型选择、设置入口和 Electron 视图均存在。其配置接口读出 373 个设置、72 个可用模型，目录无错误。
- 截图：`artifacts/ui-restoration/home.png`、`artifacts/ui-restoration/settings.png`。这些是本机验证产物，不包含密钥。

## 本机交付

已安装程序关闭时，将旧界面和后端入口备份到 `release/archive/installed-ui-before-20260929-221812/`，更新 `%LOCALAPPDATA%/Programs/alpha/resources/alpha/` 下的 UI、原生 server 和 configuration 模块，然后成功启动。没有改动会话、模型凭据或用户默认配置。此次少量文件更新保留旧安装器版本登记；新完整安装包版本为 0.1.1。

完整安装包已发布为根目录 `Alpha-Setup-0.1.1-x64.exe`，便携包和安装包内的 UI/OMP/Office 探针全部通过。上一版完整归档；路径和哈希见 [发行归档](2026-09-29-release-archive.md)。

## 边界

这不是旧设置页的逐项复刻：OAuth 新登录流程、复杂对象/数组配置和旧插件管理页尚未转成新的图形表单；原生标量参数中部分说明仍为英文。项目配置仍按 OMP 原生优先级覆盖全局配置；环境变量凭据可能优先于保存的 Key。当前安装实例启动时更新检查失败，界面提供重试；这不阻断本地配置和模型使用。
