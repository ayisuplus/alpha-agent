# 侧边栏与更新提醒控件修复

2026-09-30，用户在内置浏览器试用时发现左侧栏无法展开/收起，更新横幅无法关闭。

原因：原生界面的左侧栏采用固定列宽，没有折叠状态或切换按钮；更新横幅只有发布说明入口，没有关闭动作。这两项在前一轮定版检查中遗漏。

## 修复行为

- 侧栏左上角提供展开/收起按钮。收起时保留新会话、模型与账号、技能、定时任务、本机能力和设置图标；展开后恢复搜索与会话列表。各布局和宽度断点使用同一侧栏宽度变量。
- 侧栏状态按既有界面偏好方式存入 localStorage，同一页面来源刷新后保留；服务更换端口时不承诺沿用该来源的界面偏好。
- 更新横幅提供关闭按钮。关闭版本记录保存到 `.alpha/native/omp-update.json`，同版本刷新/重启后不再显示横幅或触发桌面通知，更高版本仍可提醒。“关于”页保留版本信息与手动检测入口。

## 验证

- `bun run check` 与 `bun run build:desktop-ui` 通过。
- `bun run test`：73 项通过、0 失败、505 次断言、14 个文件。更新监控回归覆盖错误版本拒绝、关闭记录重启恢复和新版本仍可提示。
- 当前内置浏览器实测：展开宽度约 256px → 收起约 56px → 刷新仍为 56px → 重新展开约 256px，搜索恢复可见；收起状态下技能入口可打开。
- 更新横幅关闭后不可见，刷新后仍不可见；关闭请求通过真实服务保存。
- 证据：`artifacts/sidebar-controls-2026-09-30/` 中的 `tests.log`、`browser-checks.json`、`collapsed.png`、`expanded.png`。

在确认没有工作中会话或执行中计划后，重启本轮自建试用服务并更新了用户的内置浏览器标签；服务保持运行。没有发送模型任务，没有修改模型/账号配置。
