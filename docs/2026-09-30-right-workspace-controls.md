# 右侧工作区入口与终端恢复修复

日期：2026-09-30

## 问题与改动

原生 UI 的右栏只有浏览器、文件和诊断日志，没有常驻的重新打开入口；设置中隐藏右栏后无法直接恢复，820px 以下更被 CSS 完全隐藏。终端入口则把 TUI 放在中间对话区，审查入口缺失。

- 最右侧常驻“审查 / 终端 / 浏览器”按钮，首页、会话页、设置页均可进入工作区；右栏顶部提供收起按钮。视图与显示偏好保存在当前浏览器的 localStorage。
- 审查读取选中项目的真实 Git 状态、暂存与未暂存 diff，并列出会话工具回传的产物路径。显示项目整体改动，不推断哪些改动属于当前会话；未跟踪文件只列路径。非 Git 项目明确显示能力边界。
- Git 读取限制在选中项目目录，禁用外部 diff、textconv 与 fsmonitor，不刷新索引；输出设有大小上限。
- 终端页复用现有原生 OMP TUI，显示启动 / 关闭控制；忙碌会话仍由现有单写者约束禁止切换。收起右栏不停止终端，刷新后重新选择会话可以恢复终端画面。
- 终端输入和尺寸同步改用统一的鉴权请求，支持桌面 token 与网页预览 token；失败可见。
- OMP 在空会话尚未落盘时也分配 session id。RPC 与 TUI 切换现在只恢复真实存在的会话文件，空目录可以新建；已有文件却找不到记录 id 时明确失败，保留文件。主动切换不再误报进程崩溃，恢复 RPC 后清除旧的停机提示。
- SSE 事件流取消单请求空闲超时；重连成功时清除相应的断线提示。
- 窄窗口右栏改为可收起的覆盖面板，右侧入口保持可见。

## 验证

- `bun run check` 与 `bun run build:desktop-ui` 通过。构建仍有既存的大 chunk 提示。
- `bun run test`：76 pass、0 fail，530 项断言，15 个文件；原始日志见 `artifacts/right-workspace-2026-09-30/tests-final.log`。
- Git 回归包含真实仓库的暂存、未暂存、未跟踪与子目录边界，并核对读取前后索引字节一致。
- 终端回归使用独立临时 OMP 配置与假密钥，禁用测试配置内的初次引导；验证空 RPC 会话进入 TUI、输入 `/alpha`、接收 `alpha_office` 概况、停止并恢复 RPC，未发起模型推理。
- SSE 回归在闲置 125 秒后执行 `get_state`，确认同一流仍收到响应。
- 内置浏览器实测右栏打开 / 收起 / 再打开、终端输入、刷新后重新选择运行中的终端、关闭后回到对话，以及 780px 窄窗口下的真实项目审查。

## 试用与边界

当前试用服务的启动记录在 `artifacts/right-workspace-2026-09-30/startup-final.json`，数据根目录为其中的 `workspace`。它是独立的试用数据目录；审查会话的工作目录仍为当前项目。

网页预览可以进入浏览器面板，但网页显示与接管依赖 Alpha 桌面版的 Electron 浏览器宿主。此次没有在网页预览中伪造宿主，也没有验证桌面宿主的实际接管。

现有安装包与源码发布包没有重打，仍是之前的构建。此修复交付为工作区源码、UI 构建及当前试用服务。

工具的自动审批拒绝停止旧预览服务，未执行或绕过该操作；旧服务保留，新版使用独立数据目录，避免共享 Alpha 会话数据。
