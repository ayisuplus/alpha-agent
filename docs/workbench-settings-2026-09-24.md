# 工作台设置与周边功能（2026-09-24）

本轮接续 `ui/workbench-settings` 的四阶段计划。设置与布局已在 `68e4b45`，模型管理在 `11e7f7b`，任务管理、命令面板与报告导出在 `2e8881a`。第四阶段增加诊断、空间统计、受限预览清理和新任务准备检查。

- 模型来自 OMP 共享凭据库；全局默认可被单个任务覆盖，worker 继承任务实际模型。API Key 从不返回界面。真实凭据只读查看；增删 Key 与连接测试只在隔离凭据库中验证。
- 任务标题、置顶和归档保存在 `.alpha/workbench.json`，不改变任务账本；归档不删除产品或证据。报告从已有目标、运行记录、验收证据和源码快照生成 Markdown。
- 诊断读取当前模型、ComfyUI、桌面 CDP、目录和版本状态；离线服务只显示不可用，不自动启动。新任务没有可用模型时不能启动，ComfyUI 和桌面浏览器不可用时给出说明。
- 空间统计按产品、预览、证据、构建日志、模型会话和其他运行数据列出。清理只识别带匹配清单的 UUID 预览目录，排除在线预览和任何任务当前引用的预览；目录或内部出现符号链接时跳过，删除前复核解析后的路径。界面另有确认步骤。本轮没有在真实工作区执行清理。

验证：`bun run check`、`bun run test`（52 项）和 `bun run build:desktop-ui` 通过。隔离 API 测试验证了错误 Origin 被拒绝、任务元数据持久化、当前预览不被清理、过期预览确实被删除；隔离桌面实例验证了模型选择、任务菜单、命令面板、诊断页、空间统计和首次启动提示。Electron CDP 的 `Page.captureScreenshot` 在该实例超时，因此没有本轮界面截图；交互验证使用了实际桌面实例的 DOM 与服务端状态。没有运行真实模型任务，也没有改动真实 OMP 凭据或启动 ComfyUI。
