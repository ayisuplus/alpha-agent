# 内容创作专家扩展（面向中国媒体）

> 归档（2026-09-30）：本文记录已放弃或已被取代的旧架构与方案，不代表当前版本。当前方向见 [原生 OMP 重构](../2026-09-29-omp-native-refactor.md) 与 [定版收束建议](../2026-09-30-final-convergence-recommendations.md)。

日期：2026-09-27。本轮在不改动现有 13 个核心专家人设与 Skill 的前提下，为内容创作线新增 7 个面向中国媒体平台的专家，每人一份独立人设和一份聚焦 Skill。项目协作规范见根目录 [AGENTS.md](../../AGENTS.md)，来源与口径见 [SOURCES.md](../../presets/agents/SOURCES.md)。

## 设计原则

- 原有三位内容专家保持"内容本体"职责：叶知管选题与文案主干、陆叙管剧情剧本、江见管视觉与音画；新增专家负责"平台化增长、直播、复盘、合规"，不与内容本体职责重叠。
- 平台机制（算法权重、流量阈值、活动规则）时效性强且官方与博主口径不一：所有数字只作待核实线索，Skill 统一要求动手前查官方/真实页面并注明核对日期，不向用户承诺播放、涨粉与成交。
- 合规前置：2026 年短视频强制内容标注（虚构演绎、AI 生成、营销信息、转载、个人观点、无需标注）与广告法、特殊品类资质是发布前必过项，单设合规专家在定稿前卡点。

## 工作流与交接

```
定位/选题（叶知 + 平台专家）
   → 剧情剧本（陆叙，剧情类需要时）
   → 视觉与成片（江见）
   → 平台化改编与发布物料（齐跃 / 苏迟 / 柯柠 / 沈渡）
   → 直播承接（霍场，需要时；预热物料回流给平台与视觉专家）
   → 发布前合规审核（严恪，定稿前卡点）
   → 发布与首小时运营（平台专家，按当前授权）
   → 数据复盘（宋衡）→ 反哺下一轮选题与定位
```

交接按任务需要发生，不强制每个环节都走一遍；调度与最终验收仍由主代理负责。

## 验证方法

- Skill 结构校验：`python skill-creator/scripts/quick_validate.py`（覆盖全部 20 份 Skill）。
- 专家测试：`bun test ./test/agent-presets.test.ts`，覆盖 20 类专家的检索匹配、Skill 快照读取、数量断言与迁移行为。
- 回归与类型：`bun run check`、`bun test ./test`、`bun run build:desktop-ui`。

结构校验与单元测试只证明格式正确、可被检索和派发，不代表各平台真实流量表现，也不替代平台审核与人工视听验收；后续按真实工单结果局部修订。
