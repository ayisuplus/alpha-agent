# 任务审阅与运行中指导（2026-09-24）

> 归档（2026-09-30）：本文记录已放弃或已被取代的旧架构与方案，不代表当前版本。当前方向见 [原生 OMP 重构](../2026-09-29-omp-native-refactor.md) 与 [定版收束建议](../2026-09-30-final-convergence-recommendations.md)。

初始 Git 基线为 `4033aec`。顶层 `products/`、`.alpha/` 和 `release/` 属于本机运行数据或发布产物，不纳入源码提交；两个 `reference/` 仓库以固定提交的 submodule 保留。

本轮工作台新增三条可追溯链路：

- 每个任务的状态、工具结果、模型输出和补充要求写入 `.alpha/activity/<task-id>.jsonl`，按独立操作 ID 在工作台展开。旧任务没有事后补造的事件，但仍可查看原有账本和证据。
- 验收列表保留历史记录，区分当前目标/源码/预览对应的最新证据；点击记录可查看失败原因、步骤、构建日志与存在的截图。证据文件由账本中的 ID 定位，服务端只读取真实路径位于本机 `.alpha/` 内的文件。
- 每轮模型执行前后保存受支持的文本源码快照，工作台可查看变动文件的修改前后内容。构建目录、依赖和二进制媒体不进入源码对照；单个过长文本文件仅展示前 256000 字节。

模型会话正在执行时，补充要求先写入任务账本，再调用 OMP `steer`。状态依次为“已记录”“已投递”“已处理”；会话尚未接收或中断时不宣称已处理。任务空闲或已停止时可“保存到下轮”，随后从“继续修复”入口处理；构建或浏览器验收正占用任务时等待该操作结束，不向已经结束的模型会话伪造投递。

验证：`bun run check`、`bun run test`（34 项）与 `bun run build:desktop-ui` 通过；隔离 API 测试拒绝读取 `.alpha/` 外的证据，并验证停止任务保存下轮要求；内置浏览器实际打开失败步骤、任务过程和源码前后对照。隔离真实模型任务在运行中接受补充要求，账本记录从 delivered 变为 processed，产物出现明确的 Reset 按钮与绿色计数按钮。该探针没有桌面 CDP 端口，因此浏览器验收仍为待处理，未计作完整产品通过。便携版 `release/alpha-portable-2026-09-24T03-33-26-979Z/Alpha.cmd` 用自身 Bun 与 Electron 启动；桌面工作台和预览视图探针通过，包内关键源码与 UI 文件哈希匹配本次构建。读取已有 11 个任务时，证据列表可内部滚动，任务过程不会被长列表推离页面。
