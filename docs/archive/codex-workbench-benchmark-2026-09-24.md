# Alpha 任务工作台对照记录（2026-09-24）

> 归档（2026-09-30）：本文记录已放弃或已被取代的旧架构与方案，不代表当前版本。当前方向见 [原生 OMP 重构](../2026-09-29-omp-native-refactor.md) 与 [定版收束建议](../2026-09-30-final-convergence-recommendations.md)。

本轮对照对象是 Codex 桌面的任务工作流。官方资料强调按项目组织独立任务、查看进展和结果、在长任务中保持目标与验收标准，并在任务旁继续修订。资料：[Codex app 介绍](https://openai.com/index/introducing-the-codex-app/)、[Goal 指南](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex)、[2026-07-09 桌面更新](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)。

| 工作流 | Alpha 上一版 | 本轮结果 |
|---|---|---|
| 找回任务 | 工作台只自动显示最新任务 | 左侧列出同一数据目录内的任务，按更新时间排序，可搜索、切换；刷新后恢复所选任务 |
| 看清进展 | 显示简短状态和待验收 ID | 展示目标版本、运行状态、验收条目、最近失败原因与最近一轮工具调用数 |
| 继续修复 | 按钮发送默认修复要求 | 可填写补充要求，并沿用现有 `/resume` 接口写入同一任务账本 |
| 任务与预览对应 | 切换历史任务没有入口 | 选择任务时加载其在线预览；离线任务清空预览。另一任务运行时保留其可见浏览器，不让历史任务切换打断验收 |
| 实时事件归属 | WebSocket 事件是全局流 | 账本创建后的任务事件带 task ID；当前视图只接收所选任务的事件，任务列表仍刷新其他任务状态 |

这轮保留 Alpha 的单执行任务、单可见浏览器和本机静态 Web 产品范围。任务列表是项目内工作台导航，并不提供 Codex 的多任务同时执行、Git worktree、云同步或 diff 审阅。切换到运行中任务之外的历史任务时，右侧浏览器会暂由运行中的任务使用，界面会明确提示。

验证：`bun run check`、`bun run test`（30 项）和 `bun run build:desktop-ui` 通过；隔离账本的本机 API 返回按更新时间排序的任务列表；内置浏览器实际检查了任务切换、搜索、刷新后恢复选择，以及停止任务的失败原因和继续入口；便携版从自身 `Alpha.cmd` 启动，桌面探针确认工作台与预览视图都存在。
