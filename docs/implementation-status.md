## 已验证的闭环

- OMP 18.2.11 作为唯一模型执行循环；SDK 工具面限制为 read、grep、Hashline edit、write、`alpha_build` 和可选的可见浏览器。Hashline 已通过读改与陈旧标签拒绝探针，并在真实修复任务中使用。`reference/oh-my-pi` 与 `reference/Tianshu-harness` 均保持干净。
- Electron 桌面工作台和 Bun sidecar 可独立启动。用户可在左侧提交目标、查看状态/证据、取消/恢复任务、接管/交回浏览器；右侧显示同一个真实本机预览。
- 任务账本绑定目标版本、源码指纹、构建证据、预览 ID 和浏览器证据。目标修订、源码或预览实例变化会使旧证据失效；失败时不标记完成。发布请求在同一有效实例上幂等。
- 通用 `alpha-verification.json` 在当前预览执行交互、可见文本断言、窄屏溢出、对比度和刷新检查；保存完整页面截图。接管时保存步骤检查点，交回后重新观察并继续；未确认结果的点击不盲重试。
- 模型单轮默认上限为 120 次工具调用和 15 分钟，取消与运行记录落盘。运行时负责预览与浏览器；模型的命令工具仅提供受限的构建入口，不允许其自行启动服务或清理端口。
