# Alpha 工作台视觉与交互升级 · 2026-10-01

用户已确认「极简近未来 / 日常科幻」方向并要求开始执行。本次以五个基准色建立 Alpha 自己的工作台样式，保留原生会话、模型、账号、Skill、定时任务和本机能力。执行内核与工具接口不改写。

## 为什么相同配色仍会显得廉价

这是对本次实际页面的设计判断，不是对某种颜色的普遍结论。初版将灰白画布、用户消息、选中会话同时染成浅蓝，侧栏「新会话」又使用整块高亮天蓝；导航比正文更抢眼。工具摘要、产物、消息同时使用类似的圆角框，层次主要靠重复边框表达，造成模板化的观感。

修正后，主画布使用中性白，侧栏使用灰白，用户消息使用中性浅灰；深色用炭灰的明暗建立层次。选中项使用中性色，天蓝集中在发送、焦点和运行指示。正文保持明确对比，只有输入框、菜单和抽屉使用必要的阴影。

| 基准色 | 主要职责 |
| --- | --- |
| `#1F2937` | 浅色主文字、深色内嵌表面、天蓝按钮文字 |
| `#4B5563` | 浅色次要文字 |
| `#38BDF8` | 发送按钮、焦点、运行指示 |
| `#94A3B8` | 次要图形、深色辅助文字 |
| `#F1F5F9` | 浅色侧栏、深色主文字 |

衍生色按用途分别定义，五种基准色不作为所有组件的填充色。浅色链接使用 `#0369A1`，避免天蓝小字在白底上对比不足。

## 实施范围

- 首页：静态 Alpha 字标、无衬线问候、任务输入；目录与模型在输入框内配置。替换旧蝶形半调图案、衬线问候和打字动效。
- 侧栏：Alpha、新会话、可搜索和置顶的项目会话；技能、定时任务、设置在底部。原会话归档与旧版任务继续入口保留。
- 工作区：从顶栏打开文件、浏览器、审查或终端，在面板内切换；关闭后恢复原按钮的键盘焦点。默认收起，页签和宽度继续保存。旧的「启动即展开工作区」偏好不再决定首次布局。
- 会话：相邻的两项及以上成功工具默认合并折叠；失败、运行中工具和用户提问保持显露；产物始终在折叠过程之外。文件名与预览优先，路径、校验值和原生摘要在「文件信息」内。
- 加载：打开会话时显示「正在读取会话记录」，避免用空白欢迎页替代加载状态。生成中在输入框显示停止按钮；原生 `aborted` 显示「已停止生成」，真实失败保留原因，部分正文与原始消息不丢弃。
- 证据：日常界面显示「检查建议 / 运行检查」，原始记录可展开。历史条目、内部事件名、工具名、服务商与模型标识保持原值；OMP、天枢来源、版本和许可集中在关于页。
- 主题：浅色、深色、跟随系统；字号设置继续使用用户已保存值，新用户默认 15px。宽度不超过 1100px 时工作区成为抽屉，不超过 760px 时侧栏收起；窄面板仅保留当前页签文字，其余入口有图标、名称和提示。
- 终端：新随包主题 `alpha-sky` 与 xterm 读取同一配色文件；声明真实的 xterm 色彩能力、关闭原生启动装饰。已有用户主题文件不覆盖，自定义主题选择不接管。关闭终端后忽略已卸载视图的迟到请求结果。

品牌收敛不等于改写来源声明。`LICENSE`、`NOTICE`、第三方许可和真实技术信息保持可追溯。
