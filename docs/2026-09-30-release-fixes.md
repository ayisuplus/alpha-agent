# Alpha 0.2.1 定版前修复

对应 [定版审查](2026-09-30-release-readiness-audit.md)。本轮按用户“开始修复”实施；Alpha 自有代码按用户选择采用 Apache-2.0。保留原欢迎页与纸墨界面，执行仍为原生 OMP 18.4.3。

## 已实施

- R3：进程上限只回收已结束且没有待处理 RPC/后台任务的会话。真实 shell 命令也纳入活动检查；4 个进程都忙时拒绝第 5 次打开。并发打开串行分配，避免绕过进程上限。
- R4/R5/U2/U6：计划表完整读改写串行化；等待与 prompt ID 对应的 `prompt_result`，有后台工作时再等待 `session_settled`。记录执行中、完成、失败、中止、重启中断及执行会话；忙碌目标本次跳过。支持 0/7 周日、日/星期 OR、闰日与字段范围校验。页面说明本机时区、仅运行时调度与错过触发只补一次，支持编辑和查看执行会话。
- R6：只有环境 Key、没有保存凭据的模型不再标成可用；页面提示保存。工具进程环境仍剔除凭据。
- R7/U4：所有 eval 与独立 browser 统一授权，覆盖跨代码单元保留的别名与动态属性调用。每会话独立授权文件避免跨进程覆盖；旧单文件授权不迁移，首次会重新询问。面板明确共享标签/登录态，接管需等待或停止工作中的会话，接管期间阻止新的浏览器/代码求值调用。该机制不是系统沙箱。
- R8/U1：消费文字增量和异步失败，显示空回复中的 errorMessage 与扩展通知；会话列表显示工作/等待输入/失败状态，桌面通知可跳回会话。原生改名同步持久索引。
- 侧栏：模型与账号、技能、定时任务、本机能力直达入口；标题/目录搜索、归档列表。会话顶栏提供改名、归档/恢复和 Markdown 导出。原生命令只列当前 RPC 提供的能力与真实 Skill；完整 MCP/OAuth 交互仍通过 Alpha 终端。
- U3：本机文件/目录选择器、文档附件路径、子目录浏览与文件打开；拒绝项目目录越界（含 realpath 检查），显示隐藏文件，不再截断前 120 项。
- U5：health 与媒体工具共用 `ALPHA_COMFY_URL`。服务连接不代表节点/模型准备完毕；没有启动或更换用户的 ComfyUI 服务。
- R1/R2：版本升至 0.2.1；加入 LICENSE/NOTICE、干净安装步骤、Windows CI、安全报告与贡献入口。新格式发行清单记录 Git SHA、源码/配置与 UI 哈希；探针使用独立 OMP 配置与假 Key。旧评测入口标为历史材料，修正 Skill 来源目录引用。
